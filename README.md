# 🤖 Mr Robot — Site Web & Assistant Della

Site vitrine professionnel pour **Mr Robot**, une entreprise de services techniques basée à Oran (Algérie), spécialisée en électronique, informatique, réseaux, vidéosurveillance et programmation.

Le site intègre **Della**, un assistant conversationnel intelligent propulsé par l'API NVIDIA, avec un proxy sécurisé et une journalisation des conversations.

---

## 🚀 Fonctionnalités principales

- **Design Cyberpunk / Dark Tech** : thème sombre avec animations circuit-board et effets néon.
- **Multilingue** : support du Français, Arabe et Anglais (détection automatique, sauvegarde locale).
- **Assistant IA (Della)** :
  - Chat interactif en direct.
  - Proxy sécurisé via Cloudflare Worker (clé API masquée).
  - Journalisation des conversations dans Cloudflare KV (90 jours).
  - Interface d'administration privée (`/admin`) pour consulter l'historique.
- **Contact** : double canal d'envoi (WhatsApp direct et Email).
- **Portfolio** : galerie de réalisations techniques.
- **Sécurité** :
  - Rate limiting (30 requêtes/heure par IP).
  - Protection anti-brute-force sur la page d'administration.
  - CORS restreint.
