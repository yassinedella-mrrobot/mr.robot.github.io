# 🤖 Mr Robot — Site Web & Assistant Della (v3.2 Gemini Edition)

Site vitrine professionnel et **hautement sécurisé** pour **Mr Robot**, entreprise de services techniques et d'ingénierie basée à Oran (Algérie).

---

## 📁 Structure du projet
- `index.html` : Structure HTML5, SEO, CSP stricte, image logo propre & UI Cyberpunk.
- `style.css` : Feuilles de style complètes avec mise en cache optimisée.
- `app.js` : Client scripts, multilingue (FR, AR, EN), Bot Della & Obfuscation dynamique.
- `worker.js` : Proxy Cloudflare Worker v3.2 (Moteur Google Gemini 1.5 Flash, Notifications Telegram en temps réel, KV Rate Limiting, Full Array Sanitization).
- `SECURITY.md` : Politique de sécurité et signalement responsable.
- `CNAME` : Configuration du domaine officiel (`mrrobot.qd.je`).

## 🚀 Fonctionnalités & Sécurité
- **Assistant IA Della :** Propulsé par Google Gemini 1.5 Flash avec clé API intégrée.
- **Monitoring Live :** Notification instantanée de chaque échange client directement sur Telegram (`chat_id: 5976234845`).
- **Protection Anti-DDoS & Brute Force :** Distributed Rate Limiting via Cloudflare KV (10 req/min/IP).
- **Sécurité Anti-XSS :** CSP stricte avec restriction totale sur `'self'`.
